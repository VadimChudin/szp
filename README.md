# ЛПЗС «Родина» — эмулятор пульта и ПЛК

Страница оформлена в стиле сайта [sysat.by](https://sysat.by/) и рассчитана на
отдельный пункт меню «Симулятор» (см. [DEPLOY.md](DEPLOY.md)).

Учебный 2D-тренажёр линии подготовки зерна и семян (ЕФБШ-630.01). Логика
управления перенесена из проекта ПЛК CODESYS «Rodina»: те же функциональные
блоки (`Transport`, `FB_och`, `Flapper`, `LevelSensor`), те же условия
CYCLE / NEXT / PREV у каждого механизма, те же задержки по умолчанию,
аварии, общая авария GEMER и датчики верхнего уровня. Подробно —
[docs/PLC_LOGIC.md](docs/PLC_LOGIC.md).

## Запуск

Открыть `frontend/index.html` в Chrome, Edge или Firefox — сервер не нужен.
Папки `css`, `js`, `assets` должны лежать рядом с `index.html`.

С веб-сервером (раздаёт ту же статику):

```bash
python3 -m pip install -r requirements.txt
python3 -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

Варианты развёртывания — [DEPLOY.md](DEPLOY.md).

## Как пользоваться

1. После загрузки нажат аварийный стоп на шкафу (как на реальной панели).
   Нажмите красную кнопку вверху, чтобы его отжать.
2. **Режим очистки** (справа) — выберите триеры, пневмостол, остеобрушиватель,
   ворошитель и нажмите **ПУСК**. Или **▶ Пуск режима** внизу.
3. Механизмы запускаются ПЛК с хвоста линии: каждый ждёт, пока в работе его
   следующий механизм (NEXT), и выдерживает свою задержку пуска (по умолчанию 3 с).
4. **■ Стоп режима** — штатный останов: каждый механизм отключается через свою
   задержку останова (15 с) после того, как остановился предыдущий (PREV).
5. Щелчок по механизму — окно панели: задержки, ТО, «Не отслеживать след. мех.»,
   ручной режим с кнопками ПУСК/СТОП, отключение датчиков, живые CYCLE/NEXT/PREV.
   В разделе «Имитация» — неисправности (защита, ПЧ, ДКС, ДСЛ, ДП) и местный пост.
6. **Шкаф управления** — аварийные стопы 1–5, пожарная сигнализация, контроль фаз.
7. **↺ Сброс аварий** — RESET_ERR (защёлкнутые ошибки ДКС/ДП/ДСЛ, заслонок, фаз).
8. Скорость внизу справа ускоряет модель вместе с таймерами ПЛК (×1…×20).
9. Автотранспорт: когда в завальной яме меньше 30 %, приезжает самосвал и
   ссыпает зерно на решётку; когда бункер В, А или Б заполнен больше чем на 72 %,
   под него подъезжает машина и загружается. Отключается в «Настройках → Модель»,
   машину можно вызвать и вручную из окна ямы или бункера.

Вкладки: **Оборудование** (состояние и условия пуска всех приводов),
**Аварии** (журнал и архив), **Сигналы ПЛК** (переменные программы в реальном
времени), **Настройки** (задержки ДВУ и механизмов, скорость, отображение).
Задержки, флаги отключения датчиков, режим очистки и наработка сохраняются в
браузере — аналог RETAIN-переменных.

## Устройство

```
frontend/js/plc.js     — программа ПЛК: блоки Transport, FB_och, Flapper, LevelSensor,
                         Modes, Do_Alarm_logic, DU и подключение всех 31 привода и 2 заслонок
frontend/js/plant.js   — установка за клеммами ПЛК: двигатели с разгоном/выбегом, импульсные ДКС,
                         концевики заслонок, ПЧ, уровни бункеров, движение продукта; команды панели
frontend/js/render.js  — мнемосхема на Canvas, масштаб и сдвиг
frontend/js/ui.js      — окна панели HMI, таблицы, журнал, сигналы, настройки
docs/plc/              — расшифровка цепей проекта CODESYS (исходные данные для plc.js)
tools/                 — декодер FBD/LD из файла .project, которым получена расшифровка
tests/test_plc.js      — проверки логики ПЛК и маршрутов: node tests/test_plc.js
tests/test_ui.js       — браузерная проверка интерфейса (нужен playwright)
```
