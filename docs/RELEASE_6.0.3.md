# SZP exp-v6.0.3 — предварительный выпуск

Исправления MT4/MT5: контуры top/bottom, контраст основных подписей, отступ по масштабу, перерисовка при изменении графика, очистка старых зон по []. Python: диагностика пустых/NUL-заполненных CSV. 338 тестов Python/контракта исходников прошли локально; ruff F,E9 прошёл.

Windows CI должен заново скомпилировать MQL4/MQL5 и собрать установщик. Успех CI не равен ручной проверке графика. Торговая эффективность не подтверждена, использовать сначала на демо.

## Оценка логики
Плюсы: выделены модули расчёта/экспорта/отображения; ограничение ширины по ATR; сохранение состояния активных зон; обработка отсутствия данных без генерации фиктивных свечей.
Риски: дополнительное объединение центров <=3*CLUSTER_TOLERANCE перемещает центр и не пересчитывает score; количество wick_points не равно числу независимых реакций; закрытие за границей изнутри зоны не покрывается условием body_break в active_zones._invalidate (требуется пересечение всей зоны телом от открытия до закрытия); REQUIRE_H4_ANCHOR при отсутствии H4-кандидатов не гарантирует их строгого исключения; реальные CSV истории в текущем HEAD повреждены.

Этот выпуск НЕ меняет торговые правила и не обещает прибыль. Математику нужно проверять отдельно walk-forward на настоящей истории с издержками; затем менять правила по одному и сравнивать результаты на отложенном периоде.
